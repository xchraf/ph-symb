# Logo assets

All files are official assets, downloaded from the owning organisation (or, for
CNRS and arXiv, from Wikimedia Commons where the owner's vector file is hosted).
They are used to identify the institutions the authors belong to and the
platforms the paper is published on. No file has been redrawn or recoloured.

| File | Source | Format |
|---|---|---|
| `cnrs.svg` | Wikimedia Commons, `File:Cnrs-logo.svg` (official CNRS logo) | SVG 55×55 |
| `femto-st.svg` | `femto-st.fr/themes/custom/femto/logo.svg` | SVG 205×98 |
| `umlp.png` | `umlp.fr/sites/all/themes/ufc_central/logo.png` | PNG 370×75 |
| `umlp-wordmark.png` | Cropped from the official `umlp.png` above to retain only the Université Marie et Louis Pasteur wordmark; artwork unchanged | PNG 220×75 |
| `supmicrotech.png` | `supmicrotech.fr/sites/default/files/public/logo_supmicrotech_3.png` | PNG 256×118 |
| `arxiv-mark.svg` | the X glyph of Wikimedia Commons `File:ArXiv logo 2022.svg`, cropped to its own bounding box; paths and brand colours untouched | SVG |
| `github-mark.svg` | Primer Octicons `mark-github-16` (MIT) | SVG 16×16 |

The two PNGs are rendered at roughly a quarter of their pixel width, so they
stay sharp on 3x displays. Replace them with vector files if the institutions
publish any.
